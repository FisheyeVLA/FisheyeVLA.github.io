# FisheyeVLA.github.io

Concise academic project page for **Fisheye-VLA: Decoupling Coverage and Acuity for Manipulation with a Single Fisheye Camera**.

## Preview locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Demonstration videos

Six web-optimized H.264 videos are organized into robot manipulation and observation/data-collection groups under `static/videos/`.
